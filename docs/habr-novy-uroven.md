# Оператор связи сделал игру, которая работает без связи. Как мы собрали PWA-климбер втроём

Привет, Хабр! Мы — маленькая студия (нас трое), и недавно мы выпустили
«Новый уровень»: веб-игру для мобильного оператора T2. Это бесконечный
вертикальный климбер в духе Doodle Jump — персонаж-сигнал прыгает по вышкам
связи из эпохи 2G в будущее и собирает гигабайты. Открывается по ссылке,
без установки, а после первого захода работает вовсе без интернета.

Ирония задумана: оператор связи выпускает игру, которой связь не нужна.

Под катом — почему веб, а не нативное приложение; как мы доказываем тестами,
что игрок умирает только по своей вине; и что нужно, чтобы физика прыжка
не бесила в трясущейся маршрутке.

## Почему PWA, а не приложение

У заказчика была понятная бизнес-рамка: ежедневный повод открывать экосистему,
знакомство с продуктовой линейкой (бустеры в игре названы по реальным услугам)
и виральность — лидерборд плюс шеринг рекордов. Формат: казуальная сессия
на 3–10 минут в транспорте.

Из этой рамки следует всё остальное:

- **Порог входа — ноль.** Ссылка в сторис или пуше → игра открылась. Никакого
  стора, никакого «установить 180 МБ».
- **Оффлайн обязателен.** Играют в метро и в лифте. «Требуется подключение
  к сети» в игре про оператора связи — это самострел.
- **Бюджетные телефоны — основная аудитория.** Масс-маркет, Android
  за 12 тысяч. Значит, WebGL-рендер и жёсткая дисциплина по весу.

Так «веб-игра» превратилась из компромисса в осознанный выбор: PWA с полным
оффлайном закрывает все три пункта сразу.

## Стек

Vite + React 18 + TypeScript strict — оболочка (меню, лидерборд, настройки).
Сама игра — PixiJS 8 поверх WebGL: один канвас, свой игровой цикл, React
в кадре не участвует. Состояние — Zustand. Оффлайн — Workbox, прогресс —
IndexedDB. Лидерборд — serverless-Postgres (Neon) за парой edge-функций.

Правило, которое мы приняли в первый день: **прод открыт с первого этапа**.
Каждая фича доезжает до продакшена пушем в main. «Поиграть можно уже сейчас» —
это был статус проекта с недели номер один, и это сняло примерно все споры
формата «а как оно будет ощущаться» — открой и пощупай.

## Game feel: прыжок должен быть в кайф сам по себе

Столп проекта номер один звучал так: если прыгать не в кайф — остальное
не имеет значения. Из практических следствий:

- **Автопрыжок.** Персонаж прыгает сам при касании платформы, игрок управляет
  только горизонталью — стандарт жанра, который освобождает единственный
  «канал внимания», доступный в транспорте.
- **Горизонтальный wrap.** Ушёл за левый край — вышел из правого. Мелочь,
  но она радикально упрощает и манёвры игрока, и честность генерации: вышка
  досягаема при любом x, ограничивает только высота прыжка.
- **Тюнинг на железе, а не в столе.** Гравитация и импульс прыжка подбирались
  циклами «поменяли константу → задеплоили → погоняли на реальном телефоне
  в руке». Числа, красивые в редакторе, в ладони ощущаются иначе.
- **Три схемы управления:** наклон (гироскоп), свайпы, тап-зоны. Дефолт
  выбирается по устройству, переключение — в настройках. Тест-сценарий
  у нас назывался «трясущаяся маршрутка».

Отдельный трюк: баланс (гравитация, высота прыжка, частоты спавна) лежит
в удалённом конфиге и может обновляться без релиза, а оффлайн-фолбэк —
вшитый `balance.json`. Игра без сети играется ровно так же.

## Честная генерация: «unfair death» запрещена тестом

Столп номер два: **игрок умирает только по своей вине, никогда из-за
генератора**. Красивая фраза для презентации — но как это гарантировать
в процедурной бесконечной генерации?

Ответ: планировщик уровня — чистая функция от сида, и её можно прогонять
в юнит-тестах как автоматическую версию плейтеста. Валидатор гоняет
50 сидов на глубину ~3000 метров игрового мира (весь рамп сложности) и
проверяет инварианты:

```ts
// Опорные платформы (с которых можно прыгать). Фейк — НЕ опора.
const LANDABLE = new Set<PlatformType>(['vols', 'rrl', 'moving'])

// Максимальный достижимый вертикальный зазор = высота прыжка.
// Горизонталь не ограничивает: wrap + полная дуга прыжка.
const MAX_REACH_V = balance.jump.heightPx

it('на каждом уровне есть опора (фейк никогда не спавнится один)', () => {
  for (const seed of SEEDS) {
    // ...каждый y-уровень обязан содержать хотя бы одну опорную платформу
  }
})

it('нет недостижимых разрывов: макс зазор между опорами ≤ высоты прыжка', () => {
  // ...худший вертикальный разрыв по 50 сидам сравнивается с физическим потолком
})
```

Третий инвариант — про помехи: облако-помеха не имеет права перекрывать
*единственный* маршрут к следующей опоре. Если платформа одна на уровне,
коридор до неё обязан быть чист.

Это дёшево (планировщик отделён от рендера и физики, тесты гоняются
секундами) и это единственный способ спать спокойно: любая правка баланса
или генератора мгновенно проверяется на «а не стала ли игра нечестной».

## Эпохи сетей как прогрессия

Мир растёт вместе с высотой: 2G → 3G → LTE → 5G → 6G. Меняются палитра,
фон, форма вышек; смена эпохи — кроссфейд сцен, фоновые слои живут
с параллаксом и вертикальным wrap'ом собственных частиц. Это одновременно
визуальная награда за прогресс и брендинг: слоган заказчика — «Другие
правила. Новый уровень» — игра визуализирует буквально.

Мелочь, которую мы любим: экран проигрыша на малой высоте говорит
«Застряли на 2G. Даже обидно».

## Оффлайн по-взрослому

- **Workbox** прекеширует оболочку и ассеты: второй заход открывается
  мгновенно и без сети.
- **IndexedDB** хранит прогресс (рекорды, кристаллы, настройки) — «прогресс
  не теряется никогда» был отдельным столпом качества.
- Обновления — с тостом «доступна новая версия»: новый SW не выбивает
  игрока посреди забега.
- iOS-специфика: свой install-sheet с инструкцией «Поделиться → На экран
  “Домой”», потому что Safari до сих пор не умеет нормальный install prompt.

Лидерборд — единственная сетевая фича, и он честно деградирует: нет сети —
играешь с локальным рекордом, появилась — синхронизировался.
